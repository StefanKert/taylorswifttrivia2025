# Taylor Swift Trivia App

A fun and challenging Taylor Swift trivia quiz built with React.

## Features

- 5 challenging Taylor Swift trivia questions
- 15-second timer for each question
- Immediate feedback on answers
- Score tracking
- Beautiful UI with animations
- Responsive design

## Setup

1. Clone the repository:
```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/taylorswifttrivia2025.git
cd taylorswifttrivia2025
```

2. Install dependencies:
```bash
npm install
```

3. Update the homepage URL in `package.json`:
Replace `YOUR_GITHUB_USERNAME` with your actual GitHub username.

4. Start the development server:
```bash
npm start
```

## Deployment

The app is automatically deployed to GitHub Pages using GitHub Actions. To deploy manually:

1. Make sure you have the `gh-pages` package installed:
```bash
npm install --save-dev gh-pages
```

2. Deploy to GitHub Pages:
```bash
npm run deploy
```

## GitHub Pages Setup

1. Go to your repository settings on GitHub
2. Navigate to "Pages" in the sidebar
3. Under "Source", select "gh-pages" branch
4. Save the settings

Your app will be available at: `https://YOUR_GITHUB_USERNAME.github.io/taylorswifttrivia2025`
